# Vintage macOS Portfolio

A nostalgic portfolio website with authentic Mac OS X Aqua interface design, featuring draggable windows, a classic dock, and Frutiger Aero aesthetic.

## Technologies

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- React Draggable

## Getting Started

### Prerequisites

Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Installation

```sh
# Install dependencies
npm i

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

The development server runs on http://localhost:8080

## Project Structure

- `/src/components` - Reusable UI components
- `/src/components/windows` - Content window components
- `/src/components/ui` - shadcn/ui components
- `/src/pages` - Page components
- `/src/assets` - Images and static assets

## Features

- Authentic Mac OS X Aqua UI design
- Draggable, stackable windows
- Classic macOS dock with hover effects
- Vintage Frutiger Aero aesthetic
- Responsive design
- Contact form integration with EmailJS
